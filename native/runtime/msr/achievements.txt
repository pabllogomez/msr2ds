# msr-native's achievements (runtime/msr/achievements.cpp): local only, kept in user/msr/achievements.ini, never sent
# anywhere. Inspired by Metroid II's set on RetroAchievements, fitted to the remake. This file is built into the program;
# an achievements.txt beside settings.ini replaces it (same format), so the list can be changed without a new build.
#
#   id | category | name | description | condition & condition & ...
#
# Conditions (achievements_eval.h):
#   item ITEM_NAME >= N     an item of Samus's inventory (1 for an upgrade she has, a count for capacities)
#   scenario s010_area1     the map she is in (packs/maps/<folder>)
#   metroids_left <= N      the Metroids left, as the touch screen's bar counts them
#
# Item names marked UNVERIFIED in docs/conquistas-estado-do-jogo.md are guessed: the log names, at the first moment in
# play, every item name the game has ("achievements: the game's item names: ...") and each name of this list it lacks.
